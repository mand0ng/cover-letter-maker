# Running CoverBuilder AI

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

4. **API Key**: This app requires a Gemini API Key to work. You can get one for free at [Google AI Studio](https://aistudio.google.com/). You will enter it directly in the app's settings (click the arrow icon in the "Create your Letter" box).

**Note:** The scraping service (Jina Reader) is free of charge.
